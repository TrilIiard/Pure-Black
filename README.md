## Pure Black theme for Home Assistant


Installation:

<br>

 With HACS (recommended)

(If you're not yet using the [Home Assistant Community Store (HACS)](https://hacs.xyz/), then do that first and come back here.)

- Open HACS from within Home Assistant
- Add Custom Repository "https://github.com/TrilIiard/Pure-Black"
- Search for "pure"
- Click on "Pure Black Theme"
- Click "Download"

<br>

Without HACS

Download the **pureblack.yaml** file from the themes folder in this repository and copy it to your themes folder in Home Assistant.


<br>
You will need to refresh your Browser or clear cache of Browser or Home Assistant Companion App.
Sometimes you need to reload "All YAML configuration" in Home assistant Tools. Activate the theme in your Profile in Home Assistant.
